Research Influences
Hybrid detection — Paper 1 Supervised + unsupervised signals catch different failure modes. XGBoost for labeled patterns; autoencoder for novelty without labels.
PR-AUC & SMOTE discipline — Paper 2 ROC-AUC misleads at 96%+ class imbalance. SMOTE applied before CV leaks synthetic minority samples into validation — inflates scores silently.
Alert fatigue reframing — Paper 3 Industry FP rate ~54% causes operators to stop reading alerts. Reducing FP rate became the primary engineering goal, not accuracy.
Streaming quality gates — Paper 4 Data quality must be validated before reaching the model. A bad reading produces a confident wrong prediction — and erodes trust further.
Engineering Decisions
metric PR-AUC over accuracy — a model predicting "normal" always scores 97% on a 3% failure class
SMOTE Applied inside each CV fold only — never globally — to prevent validation leakage
threshold Three configurable modes instead of a fixed cutoff — tradeoff depends on operational cost context
local LLM Ollama + Llama 3.2 — data privacy, no cloud dependency, deterministic latency, rule-based fallback
JSONB Flexible sensor payloads per machine type — avoids schema migrations as sensor configs change
CI/CD GitHub Actions + Docker from day one — reproducible by design, not retrofitted after "it works locally"
